# Todo Editing

## Overview
Users need to be able to correct mistakes in existing todo items without deleting and re-adding them.

## Acceptance Criteria

- Given a todo item exists in the list, when the user double-clicks its text and types a new value then presses Enter, the todo should display the updated text.
- The total number of todos should remain unchanged after an edit.

## Notes
- Double-clicking the todo label activates edit mode
- Pressing Enter confirms the edit
- The edited item should remain in its current position in the list
